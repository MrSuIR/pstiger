# Модуль MsilCodegen

Модуль отвечает за генерацию промежуточного кода MSIL и AST программы.

* Для генерации кода используется класс `ILGenerator` платформы .NET
* Все функции программы на языке Tiger превращаются в методы класса `Program` в .NET
* Все типы данных языка Tiger преобразуются в соответствующие им типы .NET
