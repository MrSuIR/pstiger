# Модуль MsilBackend

Модуль отвечает за генерацию исполняемого файла платформы .NET (.NET Assembly).

* Для создания исполняемого файла используется `PersistedAssemblyBuilder`, добавленный в .NET9+
* Для правильного запуска этого файла на Linux / Mac OS X генерируется файл `runtimeconfig.json`
    * Этот файл используется утилитой `dotnet exec` для выбора .NET нужной версии
    * Этот файл не нужен в Windows, где программы на .NET поддерживаются напрямую загрузчиком опрационной системы

Генерацию промежуточного кода MSIL из AST программы выполняет другой модуль — `MsilCodegen`.
