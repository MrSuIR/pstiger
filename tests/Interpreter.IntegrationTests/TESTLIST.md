# Список тестов синтаксического анализатора Kaleidoscope

## Выражения с операторами

- [x] Разбор арифметических выражений с учётом приоритета
    - `1 + 2 * 8 / 3 - 1` → 5
- [x] Разбор арифметических выражений с учётом скобок
    - `(1 + 2) * (8 / (3 - 1))` → 12
- [x] Проверка левоассоциативности арифметических операций:
    - `10 - 3 - 2` → 5
    - `10 / 3 / 2` → 1
    - `10 - 3 + 2` → 9
    - `10 / 3 * 2` → 6
- [ ] Разбор унарного минуса:
    - `-4` → -4
    - `2 * 2 * --5` → 20
- [ ] Разбор операторов сравнения
    - `1 + 2 < 5` → 1
    - `2 * 2 > 5` → 0
    - `2 * 2 = 5` → 0
    - `2 / 2 <> 4` → 1
    - `2 * 2 >= 4` → 1
    - `2 - 1 <= 1` → 1
- [ ] Проверка отсутствия ассоциативности сравнений:
    - `1 < 2 < 3` → ошибка
    - `1 = 2 = 3` → ошибка
    - `1 = (2 = 3)` → 1
- [ ] Разбор логических операторов
    - `1 & 0` → 0
    - `3 | 2` → 1

## Встроенные функции

- [ ] Функции вывода
    - `print("Hello!")` → выводится "Hello!"
    - `printi(2 + 7)` → выводится "9"
    - `(printi(2 + 7); print("\n"); printi(2 - 7); print("\n")` → выводится "9\n-5\n"
    - `flush()` → вызывает метод Flush()
- [ ] Функция ввода
    - `print(getchar())` → выводит введённый символ
- [ ] Функции преобразования символов
    - `chr(ord("Hello"))`→ "H"
    - `ord("0")` → 48
    - `chr(49)` → "1"
    - `ord("")` → -1
    - `chr(2025)` → аварийный останов
- [ ] Функции работы со строками
    - `size("Hello!")` → 6
    - `substring("Hello!", 2, 2)` → "ll"
    - `substring("Hello!", 2, 10)` → "llo!"
    - `concat("Ali", "ce")` → "Alice"
- [ ] Логические функции
    - `1 & not(0)` → 1
    - `0 | not(2)` → 0
- [ ] Функция завершения программы
    - `(print("Hello, "); exit(0); print("World!")` → выводит "Hello, ", код возврата 0
    - `(print("Hello, "); exit(1))` → выводит "Hello, ", код возврата 1

## Особенности выражений

- [ ] Разбор последовательности выражений в скобках
    - `(2 * 2; 2 * 5)` → 10
- [ ] Вычисления по короткой схеме
    - `1 & (printi(2); 0)` → 0, выводится число "2"
    - `0 & (printi(0); 0)` → 0, не выводится ничего
    - `0 | (printi(2); 0)` → 0, выводится число "2"
    - `1 | (printi(0); 0)` → 0, не выводится ничего
