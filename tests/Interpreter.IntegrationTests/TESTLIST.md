# Список тестов синтаксического анализатора Kaleidoscope

## Выражения с операторами

- [x] Разбор арифметических выражений с учётом приоритета
    - `1 + 2 * 8 / 3 - 1` → 5
- [x] Разбор арифметических выражений с учётом скобок
    - `(1 + 2) * (8 / (3 - 1))` → 12
- [x] Проверка левоассоциативности арифметических операций:
    - `10 - 3 - 2` → 5
    - `10 / 3 / 2` → 1
    - `10 - 3 + 2` → 9
    - `10 / 3 * 2` → 6
- [x] Разбор унарного минуса:
    - `-4` → -4
    - `2 * 2 * --5` → 20
- [x] Разбор операторов сравнения
    - `1 + 2 < 5` → 1
    - `2 * 2 > 5` → 0
    - `2 * 2 = 5` → 0
    - `2 / 2 <> 4` → 1
    - `2 * 2 >= 4` → 1
    - `2 - 1 <= 1` → 1
- [x] Проверка отсутствия ассоциативности сравнений:
    - `1 < 2 < 3` → ошибка
    - `1 = 2 = 3` → ошибка
    - `1 = (2 = 3)` → 0
- [x] Разбор операций сравнения строк
    - `"Hello" = "Hello!"` → 0
    - `"Hello" <> "Hello!"` → 1
    - `"Bob" > "Alice"` → 1
    - `"Bob" < "Alice"` → 0
    - `"Bob" >= "Alice"` → 1
    - `"Bob" <= "Alice"` → 0
- [x] Разбор логических операторов
    - `1 & 0` → 0
    - `3 | 2` → 1
- [x] Разбор последовательности выражений в скобках
    - `(2 * 2; 2 * 5)` → 10

## Встроенные функции

- [x] Функции вывода
    - `print("Hello!")` → выводится "Hello!"
    - `printi(2 + 7)` → выводится "9"
    - `(printi(2 + 7); print("\n"); flush(); printi(2 - 7); print("\n")` → выводится "9\n-5\n"
    - `(printi(7); flush(); printi(4))` → вызывает метод Flush()
- [x] Функция ввода
    - `print(getchar())` → выводит введённый символ
- [x] Функции преобразования символов
    - `chr(ord("Hello"))`→ "H"
    - `ord("0")` → 48
    - `chr(49)` → "1"
    - `ord("")` → -1
    - `chr(2025)` → аварийный останов
- [x] Функции работы со строками
    - `size("Hello!")` → 6
    - `substring("Hello!", 2, 2)` → "ll"
    - `substring("Hello!", 2, 10)` → "llo!"
    - `concat("Ali", "ce")` → "Alice"
- [x] Логические функции
    - `1 & not(0)` → 1
    - `0 | not(2)` → 0
- [x] Функция завершения программы
    - `(print("Hello, "); exit(0); print("World!"))` → выводит "Hello, ", код возврата 0
    - `(print("The End"); exit(1))` → выводит "The End", код возврата 1
- [x] Вычисления логических операций по короткой схеме
    - `1 & (printi(2); 0)` → 0, выводится число "2"
    - `0 & (printi(0); 0)` → 0, не выводится ничего
    - `0 | (printi(2); 0)` → 0, выводится число "2"
    - `1 | (printi(0); 0)` → 1, не выводится ничего

## Негативные тесты (нарушение семантики типов)

- [x] Нельзя проводить арифметические операции со строками:
    - `10 + 4 + "5"`
    - `"cat" + 0`
    - `"hot" + " " + "dog"`
    - `"cat" * 2`
    - `"ten" / 2`
    - `"10" - 5`
    - `-"one"`
- [x] Нельзя проводить логические операции со строками:
    - `1 & "5"`
    - `0 & "5"`
    - `(1 | "cat") | 1`
- [x] Нельзя сравнивать строки с числами:
    - `10 < "11"`
    - `"one" > 2`
    - `10 <= "11"`
    - `"one" >= 2`
    - `"infinity" = 19`
    - `"infinity" <> 10`
- [x] Нельзя проводить арифметические и логические операции с операндом, не возвращающим значения
    - `10 + ()`
    - `() * 2`
    - `() & ()`
    - `1 | ()`
    - `1 | (2; ())`

## Негативные тесты (ошибки вызова функций)

- [x] Нельзя вызвать неизвестную функцию
    - `length("Hello!")`
- [x] Нельзя вызвать встроенную функцию с неправильными типами аргументов
    - `size(10)`
- [x] Нельзя вызвать встроенную функцию с неправильным числом аргументов
    - `size("Hello!", "World")`
    - `size()`

## Переменные

- [x] Объявление и присваивание переменных типа int
- [x] Объявление и присваивание переменных типа string
- [x] Можно скрыть встроенную функцию своей переменной
- [x] Допускается `var ... in end` без выражения между `in` и `end`

## Переменные (негативные тесты)

- [x] Присваивание не возвращает результата: `a := b := 0` недопустимо
- [x] Выражение слева в присваивании должно быть lvalue

## Негативные тесты (семантические ошибки, связанные с переменными)

- [x] Нельзя использовать необъявленную переменную
- [x] Нельзя инициализировать переменную значением другого типа
- [x] Нельзя использовать переменную, объявленную в другой области видимости
- [x] Нельзя вызывать переменную как функцию
- [x] Нельзя вызывать встроенную функцию, если её имя перекрыто переменной
- [x] Нельзя присвоить переменной значение другого типа
- [x] Нельзя повторно объявлять переменную с тем же именем в одной области видимости

## Ветвления if...then...else

- [x] Ветвление с веткой then без else
- [x] Ветвление с ветками then и else без возвращаемого значения
- [x] Ветвление с ветками then и else с возвращаемым значением
- [x] Нет проблемы висячего else

## Негативные тесты (ветвления)

- [x] Условие должно быть целочисленным выражением
- [x] Ветка then в отсутствие else не может возвращать значение
- [x] Ветки then и else должны возвращать значения одного типа данных

## Пользовательские функции

- [x] Функция без параметров
- [x] Функция с одним параметром
- [x] Функция с несколькими параметрами
- [x] Процедура без параметров
- [x] Рекурсивный вызов функции
- [x] Взаимная рекурсия функций
- [x] Можно скрыть встроенную функцию объявлением пользовательской функции
- [x] Функция захватывает переменные окружающей области видимости

## Негативные тесты (пользовательские функции)

- [x] Нельзя вызывать процедуру там, где ожидается возврат значения
- [x] Нельзя передавать в функцию неправильное число параметров
- [x] Нельзя передавать в функцию параметры неподходящих типов
- [x] Нельзя использовать в функции переменные, недоступные в её области видимости
- [x] Нельзя возвращать из функции значение типа, не соответствующего заявленному

## Циклы

- [x] Цикл while не выполняется, если условие изначально ложно
- [x] Цикл while выполняется до тех пор, пока условие истинно
- [x] Цикл for выполняется с шагом 1 от нижней до верхней границы (включительно)
- [x] Цикл for выполняется однократно, если нижняя и верхняя границы равны
- [x] Цикл for не выполняется ни разу, если нижняя граница больше верхней
- [x] Итератор цикла for может скрыть переменную внешней области видимости
- [x] Инструкция break прерывает ближайший к ней цикл while или for

## Негативные тесты (циклы)

- [x] Цикл while нельзя использовать там, где ожидается возврат значения
- [x] Выражение условия в цикле while может возвращать только целочисленный тип
- [x] Тело цикла while не может возвращать значения
- [x] Первые два выражения в цикле for могут возвращать только целочисленный тип
- [x] Итератору цикла for нельзя присвоить значение
- [x] Цикл for нельзя использовать там, где ожидается возврат значения
- [x] Тело цикла for не может возвращать значения
- [x] Область видимости итератора цикла ограничена самим циклом
- [x] Инструкция break не допускается за пределами циклов
- [x] Инструкция break не допускается, если цикл объявлен в одной из вызывающих функций и отсутствует в вызванной

## Объявления типов (позитивные тесты)

- [x] Можно объявить синоним встроенного типа
- [x] Можно объявить тип одномерного массива строк
- [x] Можно объявить тип двумерного массива целых чисел
- [x] Можно объявить тип, перекрыв имя встроенного типа
- [x] Можно использовать одно имя для типа и для переменной/функции в одной области видимости

## Объявления типов (негативные тесты)

- [x] Нельзя объявить два типа с одинаковым именем
- [x] Нельзя объявить переменную несуществующего типа

## Массивы (позитивные тесты)

- [x] Можно создать одномерный массив чисел, присвоить и прочитать его элементы
- [x] Можно создать двумерный массив чисел, присвоить и прочитать его элементы
- [x] Присваивание переменных с типом массива создаёт ссылку на массив, а не его копию
- [x] Массив передаётся в функцию по ссылке, а не по значению
- [ ] Массив существует после завершения области видимости, в которой был создан
- [ ] Сравнение массивов сравнивает их по ссылке, а не по значениям элементов
- [ ] Можно сравнивать массивы разных типов, если эти типы являются синонимами

## Массивы (негативные тесты)

- [ ] Для массивов не действует оператор сравнения `<`
- [ ] Для массивов не действует оператор сложения `+`
- [ ] Нельзя сравнивать массивы разных типов, если эти типы не являются синонимами
- [ ] Индекс массива должен быть целым числом
- [ ] Нельзя запрашивать элемент массива у переменной, не являющейся массивом
- [ ] Индекс массива не должен выходить за границы массива при выполнении программы
- [ ] Нельзя для инициализации массива использовать значение типа, отличного от типа элементов
- [ ] Нельзя использовать для литерала массива тип, не являющийся массивом
