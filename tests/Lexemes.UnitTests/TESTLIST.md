# Список тестов

## Идентификаторы и ключевые слова

- [x] Разбор идентификаторов: `alice Bob C00L D_2 x`
- [x] `type  arrtype = array of int` — type, array, of
- [ ] `let var x := 0 in x end` — let, var, in, end
- [ ] `while isdigit(buffer) do break` — while, do, break
- [ ] `if n = 0 then 1 else n * factorial(n-1)` — if, then, else
- [ ] `for i:=10 to 20 do printi(i)` — for, to
- [ ] `function foo() = ()` — function
- [ ] `if a=nil then b` — nil

## Литералы

- [ ] Разбор литералов целых чисел: `0 1234 56789 00173`
- [ ] Разбор строк: `"" "0" "Hello, world!"`
- [ ] Разбор простых escape-последовательностей: `"\n\t\"\\"`
- [ ] Разбор escape-последовательностей в каретной нотации: `"\^@" "\^A\^C\^Z" "\^[" "\^\" "\^]" "\^^" "\^_" "\^?"`
- [ ] Разбор escape-последовательностей с номером ASCII-символа: `"\040\041\042"`
- [ ] Разбор многострочных литералов с пропуском пробельных символов между двумя `\`

## Операторы, разделители и скобки

- [ ] `x + y / (10 - z * 2)` — операторы `+, -, *, /`, скобки `()`
- [ ] `a < b | a > c | b = c` — операторы `<, >, =, |`
- [ ] `a <= b & b >= c & a <> c` — операторы `<=, >=, <>, &`
- [ ] `speed.x := v[0]` — операторы `.`, `:=`, скобки `[]`
- [ ] `type list = {first: int, rest: list}` — скобки `{}`, разделители `':', ','`
- [ ] `(foo(x);0)` — разделитель `;`

## Пробелы и комментарии

- [ ] Пропуск пробельных символов: `' '`, `'\t'`, `'\r'`, `'\n'`, `'\f'`
- [ ] Комментарии: `/* ... */`
- [ ] Вложенные комментарии: `/* ... /* ... */ */`
