# Виртуальная машина Tiger

Виртуальная машина Tiger выполняет инструкции по определённым правилам, тем самым обеспечивая возможность вычисления любой программы на Tiger.

Эта статья описывает принцип работы (модель работы) виртуальной машины Tiger.

## Модель виртуальной машины

Структура машина Tiger состоит из следующих элементов:

1. Список инструкций, составляющих программу;
2. Указатель на следующую инструкцию;
3. Стек значений, используемый для вычисления выражений;
4. Стек возвратов из функций, используемый для восстановления указателя на следующую инструкцию после вызова функции;
5. Стек таблиц переменных, созданных по числу областей видимости;
6. Процессор, обрабатывающий инструкции.

## Инструкции

Каждая инструкция программы содержит:

1. Код инструкции из набора инструкций
2. Значение операнда (необязательное)

## Набор инструкций

| Код              | Операнд  | Описание                                                                                                                                |
|------------------|----------|-----------------------------------------------------------------------------------------------------------------------------------------|
| LOAD             | Значение | Добавляет значение в стек значений.                                                                                                     |
| LOAD_VAR         | Имя      | Читает значение переменной, добавляет его в стек значений.                                                                              |
| STORE_VAR        | Имя      | Убирает вершину стека значений (A), записывает в переменную с указанным именем.                                                         |
| STORE_ARRAY      | —        | Убирает три значения со стека значений (A — вершина, B, C), записывает в массив C по индексу B значение A                               |
| LOAD_ARRAY       | —        | Убирает два значения со стека значений (A — вершина, B), получает элемент массива B по индексу A и добавляет его в стек                 |
| STORE_FIELD      | Имя      | Убирает два значения со стека значений (A — вершина, B), записывает в структуру B в поле с указанным именем значение A                  |
| LOAD_FIELD       | Имя      | Убирает вершину значения со стека значений (A), получает из структуры A поле с указанным именем                                         |
| POP              | —        | Убирает вершину стека значений                                                                                                          |
| ADD              | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A + B`, результат добавляет в стек значений.                        |
| SUB              | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A - B`, результат добавляет в стек значений.                        |
| MUL              | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A * B`, результат добавляет в стек значений.                        |
| DIV              | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A / B`, результат добавляет в стек значений.                        |
| AND              | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A AND B`, результат добавляет в стек значений.                      |
| OR               | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A OR B`, результат добавляет в стек значений.                       |
| EQUAL            | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A == B`, результат добавляет в стек значений.                       |
| NOT_EQUAL        | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A != B`, результат добавляет в стек значений.                       |
| LESS             | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A < B`, результат добавляет в стек значений.                        |
| LESS_OR_EQUAL    | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A <= B`, результат добавляет в стек значений.                       |
| GREATER          | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A > B`, результат добавляет в стек значений.                        |
| GREATER_OR_EQUAL | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A >= B`, результат добавляет в стек значений.                       |
| NEG              | —        | Убирает вершину стека значений (A), меняет знак A, результат добавляет в стек значений.                                                 |    
| NOT              | —        | Убирает вершину стека значений (A), выполняет логическое отрицание A, результат добавляет в стек значений.                              |
| JMP              | —        | Безусловный переход, меняет указатель инструкций                                                                                        |
| JMP_IF_TRUE      | —        | Условный переход, убирает вершину стека значений (A) и меняет указатель инструкций, если A — истина (не 0)                              |
| JMP_IF_FALSE     | —        | Условный переход, убирает вершину стека значений (A) и меняет указатель инструкций, если A — ложь (0)                                   |
| CALL_BUILTIN     | Имя      | Вызывает встроенную функцию (print, printi, flush, getchar, ord, chr, size, substring, concat), передаёт аргументы через стек значений. |
| CALL             | Номер    | Вызывает функцию, передаёт аргументы через стек значений, меняет указатель инструкций и записывает прежний указатель в стек возвратов.  |
| RETURN           | —        | Завершает функцию, возвращает результат через стек значений и восстанавливает указатель инструкций в стек возвратов                     |
| HALT             | —        | Останавливает работу программы, используя значение с вершины стека как код возврата                                                     |
