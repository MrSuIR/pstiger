# Виртуальная машина Tiger

Виртуальная машина Tiger выполняет инструкции по определённым правилам, тем самым обеспечивая возможность вычисления любой программы на Tiger.

Эта статья описывает принцип работы (модель работы) виртуальной машины Tiger.

## Модель виртуальной машины

Структура машина Tiger состоит из следующих элементов:

1. Список инструкций, составляющих программу;
2. Указатель на следующую инструкцию;
3. Стек значений, используемый для вычисления выражений;
4. Стек возвратов из функций, используемый для восстановления указателя на следующую инструкцию после вызова функции;
5. Стек таблиц переменных, созданных по числу областей видимости;
6. Входной поток (stdin);
7. Выходной поток (stdout) с буферизацией вывода;
8. Процессор, обрабатывающий инструкции.

## Инструкции

Каждая инструкция программы содержит:

1. Код инструкции из набора инструкций
2. Значение операнда (необязательное)

## Набор инструкций

| Код         | Операнд  | Описание                                                                                                                                |
|-------------|----------|-----------------------------------------------------------------------------------------------------------------------------------------|
| Push        | Значение | Добавляет значение в стек значений.                                                                                                     |
| Pop         | —        | Убирает вершину стека значений                                                                                                          |
| LoadVar     | Имя      | Читает значение переменной, добавляет его в стек значений.                                                                              |
| StoreVar    | Имя      | Убирает вершину стека значений (A), записывает в переменную с указанным именем.                                                         |
| CreateArray | —        | Убирает два значения со стека значений (A — вершина, B), создаёт массив размера B, инициализируя каждый элемент значением A             |
| StoreArray  | —        | Убирает три значения со стека значений (A — вершина, B, C), записывает в массив C по индексу B значение A                               |
| LoadArray   | —        | Убирает два значения со стека значений (A — вершина, B), получает элемент массива B по индексу A и добавляет его в стек                 |
| StoreField  | Имя      | Убирает два значения со стека значений (A — вершина, B), записывает в структуру B в поле с указанным именем значение A                  |
| LoadField   | Имя      | Убирает вершину значения со стека значений (A), получает из структуры A поле с указанным именем                                         |
| Add         | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A + B`, результат добавляет в стек значений.                        |
| Subtract    | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A - B`, результат добавляет в стек значений.                        |
| Multiply    | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A * B`, результат добавляет в стек значений.                        |
| Divide      | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A / B`, результат добавляет в стек значений.                        |
| And         | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A AND B`, результат добавляет в стек значений.                      |
| Or          | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A OR B`, результат добавляет в стек значений.                       |
| Equal       | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A == B`, результат добавляет в стек значений.                       |
| NotEqual    | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A != B`, результат добавляет в стек значений.                       |
| Less        | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A < B`, результат добавляет в стек значений.                        |
| LessOrEqual | —        | Убирает два значения со стека значений (A — вершина, B), вычисляет `A <= B`, результат добавляет в стек значений.                       |
| Negate      | —        | Убирает вершину стека значений (A), меняет знак A, результат добавляет в стек значений.                                                 |    
| Not         | —        | Убирает вершину стека значений (A), выполняет логическое отрицание A, результат добавляет в стек значений.                              |
| Jump        | Номер    | Безусловный переход, меняет указатель инструкций. Нумерация инструкций начинаются с нуля.                                               |
| JumpIfTrue  | Номер    | Условный переход, убирает вершину стека значений (A) и меняет указатель инструкций, если A — истина (не 0)                              |
| JumpIfFalse | Номер    | Условный переход, убирает вершину стека значений (A) и меняет указатель инструкций, если A — ложь (0)                                   |
| CallBuiltin | Имя      | Вызывает встроенную функцию (print, printi, flush, getchar, ord, chr, size, substring, concat), передаёт аргументы через стек значений. |
| Call        | Номер    | Вызывает функцию, передаёт аргументы через стек значений, меняет указатель инструкций и записывает прежний указатель в стек возвратов.  |
| Return      | —        | Завершает функцию, возвращает результат через стек значений и восстанавливает указатель инструкций в стек возвратов                     |
| Halt        | —        | Останавливает работу программы, используя значение с вершины стека как код возврата                                                     |
