# Лексическая структура языка Tiger

## Ключевые слова

| Слово    | Предназначение                                          |
|----------|---------------------------------------------------------|
| array    | Используется при объявлении типа                        |
| break    | Прерывание цикла                                        |
| do       | Отделяет условие от тела цикла                          |
| else     | Отделяет ветку else в ветвлении                         |
| end      | Завершает блок let..in..end                             |
| for      | Начинает цикл с итерацией                               |
| function | Начинает объявление функции                             |
| if       | Начинает ветвление                                      |
| in       | Отделяет список объявлений от тела в блоке let..in..end |
| let      | Начинает блок let..in..end                              |
| nil      | Специальное значение для неинициализированных структур  |
| of       | Указывает тип либо значение элементов массива           |
| then     | Отделяет ветку then в ветвлении                         |
| to       | Разделитель в условии цикла for                         |
| type     | Начинает объявлении типа                                |
| var      | Начинает объявление переменной                          |
| while    | Начинает цикл с условием                                |

## Идентификаторы

Идентификатор — это последовательность английских букв (a...z, A...Z), арабских цифр (0...9) и подчёркиваний "_"

- Идентификатор начинается с буквы;
- Регистр имеет значение.

## Литералы

1. Литералы целых чисел состоят из десятичных чисел: 0123456789
    - нет литералов отрицательных чисел — вместо них используется оператор "-" (унарный минус)
2. Литералы строк состоят из нуля или более элементов и окружаются двойными кавычками `"`
    - элемент строки — это печатаемые символы, пробелы или escape-последовательности

Варианты escape-последовательностей:

| Вариант | Значение                                                                                     |
|---------|----------------------------------------------------------------------------------------------|
| \\n     | Перенос строки                                                                               |
| \\t     | Табуляция                                                                                    |
| \\"     | Двойная кавычка                                                                              |
| \\\\    | Обратный слэш                                                                                |
| \\^X    | Управляющий символ от U+0000 до U+001F, где X — символ из каретной нотации                   |
| \\DDD   | Символ ASCII с кодом DDD, где D — десятичная цифра                                           |
| \\...\\ | Все пробельные символы между двумя "\\" игнорируются, что удобно для многострочных литералов |

## Пробелы и комментарии

Игнорируются пробельные символы:

- пробелы " ";
- табы "\\t";
- переносы строк "\\n";
- возвраты строк "\\r".

Комментарии начинаются с `/*` и заканчиваются `*/`:

- Комментарии могут содержать переносы строк;
- Комментарии могут быть вложенными.
