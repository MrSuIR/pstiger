# Семантика языковых конструкций

## Логические значения

1. В условиях любое ненулевое целое число интерпретируется как «истина», а число 0 — как «ложь».
2. Логические операции и операции сравнения возвращают число 1 как значение «истина» либо число 0 как «ложь».
3. Логические операции вычисляются по короткой схеме (short circuit evaluation) — если левый операнд определяет результат, то правый операнд не вычисляется

## Операторы сравнения

1. Целые числа сравниваются по значению
2. Строки сравниваются лексикографически и считаются равными, если состоят из одинаковых символов
3. Для массивов сравнение возвращает «истину» (1) тогда и только тогда, когда выражения слева и справа возвращают ссылку на один и тот же массив
    - Другими словами, массивы сравниваются по ссылке, а не по их элементам
4. Для структур, сравнение возвращает «истину» (1) тогда и только тогда, когда выражения слева и справа возвращают ссылку на одну и ту же структуру
    - Другими словами, структуры сравниваются по ссылке, а не по их полям

## Присваивания

* Присваивание не возвращает значения, поэтому конструкции вида `a := b := 0` недопустимы.
* Выражение слева от присваивания должно быть `lvalue` — другие варианты не допускаются.
* Присваивание массива создаёт лишь новую ссылку на тот же массив
* Присваивание структуры создаёт лишь новую ссылку на ту же структуру

## lvalue

`lvalue` означает «значение слева от присваивания».

Выражение lvalue может содержать:

1. Имя переменной в начале
2. Одно или несколько обращений к элементу массива и/или полю структуры после имени переменной

Правила:

* Выражения `lvalue` представляет собой место хранения значения, поддерживающее чтение и запись
* Допустимые `lvalue` — это имена переменных, имена параметров и доступ к элементам массивов
* Доступ к элементу массива или полю структуры можно повторять
    * Пример: `matrix[1][2] := 1`
    * Пример: `image.data[1][2] := 1`
    * Пример: `document.header.id := "e9f1a0be`

## Литерал массива

Пример: `intArray[2] of 0`

- В начале литерала указывается имя типа (типы элементов массива определены в объявлении этого типа)
- Выражение в квадратных скобках обозначает размер массива
- Выражение после `of` задаёт значение, используемое для инициализации всех ячеек массива
- Эти выражения вычисляются в порядке их написания (слева направо)

## Литерал структуры

Пример: `point{ x = 10, y = 15 }`

- Допускается инициализация любого числа полей, включая 0 полей
- Названия полей, типы инициализирующих выражений и порядок инициализации полей в литерале структуры должны совпадать с объявлением типа этой структуры

## Ветвления if...then...else

1. Выражение условия ветвления должно возвращать целочисленный тип
2. Если условие истинно, то вычисляется ветка then, иначе ветка else
3. Ветки then и else должны либо обе не возвращать значения, либо возвращать значения одного типа
4. Ветка else необязательна — при её отсутствии ветка then не должна возвращать значения
5. Если ветки then и else возвращают значение, то и всё выражение if...then...else возвращает значение того же типа

## Циклы while...do

1. Выражение условия цикла должно возвращать целочисленный тип
2. Пока условие истинно, тело цикла выполняется
3. Тело цикла не должно возвращать значения

## Циклы for...to...do

1. Идентификатор используется для объявления переменной-итератора, область видимости которой ограничена телом цикла
2. Переменная итератор меняется с шагом 1 от нижней границы (включительно) к верхней границе (включительно)
3. Первые два выражения должны возвращать целые числа и заданию соответственно нижнюю и верхнюю границы итератора
4. Итератору цикла нельзя присвоить значение
5. Тело цикла не должно возвращать значение
6. Если верхняя граница меньше нижней, то цикл не выполняется ни разу

## Выражение break

1. Прерывает ближайший цикл `while` или `for` в пределах своей функции
2. Не допускается за пределами циклов

## Области видимости

В языке используются лексические, а не динамические области видимости.

Есть два способа создать новую область видимости:

1. Объявить функцию — например, `function sum(a: int, b: int): int = a + b`. Все формальные параметры доступны в области видимости функции.
2. Объявить область видимости с помощью let...in...end — например, `let var n = 10 in print(n * n) end`.

При объявлении функция захватывает все переменные внешней области видимости и имеет к ним доступ при вызове.

Начало и конец области видимости внутри `let...in...end` определяется так:

* Область видимости типа начинается с объявления и заканчивается с ключевым словом `end`
* Область видимости переменной начинается с объявления и заканчивается с ключевым словом `end`
* Область видимости функции начинается с последовательности объявлений функции, в которую входит это объявление, и заканчивается с ключевым словом `end`
    * Это позволяет использовать взаимную рекурсию при объявлении функций

## Уникальность имён

Имена переменных и функций находятся в одном пространстве имён. Имена типов находятся в другом пространстве имён.

Действуют следующие правила:

1. В одной области видимости все имена должны быть уникальны:
    - нельзя использовать имя для переменной или функции, если оно уже занято другой переменной или функций
    - нельзя использовать имя для типа, если оно уже занято другим типом
    - можно использовать одно и то же имя как для типа, так и для переменной либо функции в той же области видимости
2. Во вложенной области видимости можно объявлять символ с именем, совпадающим с именем из внешней области видимости — в этом случае новый символ перекрывает старый
3. Допускается перекрывать имена встроенных функций и типов

## Передача параметров функций

1. Параметры типов `int` и `string` передаются по значению — иными словами, присваивание параметра в функции не влияет на состояние переменных в других функциях.
2. Параметры типа, являющегося массивом, передаются по ссылке — иными словами, изменение элемента массива в функции влияет на состояние этого массива, наблюдаемое по всем ссылкам на него
3. Параметры типа, являющегося структурой, передаются по ссылке — иными словами, изменение поля струткуры в функции влияет на состояние этой структуры, наблюдаемое по всем ссылкам на неё
4. Параметры можно использовать в левой части присваиваний, как и обычные переменные.
5. Фактические параметры вычисляются слева направо.
6. При вызове функции количество фактических параметров должно совпадать с количеством формальных параметров.

## Встроенные функции

1. `print(s: string)` — выводит строку в стандартный поток вывода
2. `printi(i: int)` — выводит целое число в стандартный поток вывода
3. `flush()` — записывает данные в буфере стандартного потока вывода
4. `getchar(): string` — читает один символ из stdin
    - возвращает пустую строку, если достигнут конец файла
5. `ord(s: string): int` — возвращает ASCII-код первого символа `s`
    - возвращает `-1`, если `s` пуста
6. `chr(i: int): string` — возвращает строку из одного символа для ASCII-значения `i`
    - программа аварийно завершается, если `i` вне диапазона \[0..127\]
7. `size(s: string): int` — возвращает количество символов в строке `s`
8. `substring(s: string, f: int, n: int): string` — возвращает подстроку `s`, начинающуюся с индекса `f`, длиной `n`
    - индексация символов начинается с нуля
9. `concat(s1: string, s2: string): string` — возвращает результат конкатенации строк `s1` и `s2`
10. `not(i: int): int` — если `i = 0`, то возвращает `1`, иначе возвращает `0`
11. `exit(i: int)` — завершает программу с кодом выхода `i`

## Рекурсия

1. Поддерживается рекурсия — функция может вызывать сама себя;
2. Поддерживается взаимная рекурсия — функции могут вызывать друг друга, если они объявлены в одной области видимости let...in...end и между их объявлениями нет объявлений иных категорий символов (например, переменных).

## Управление памятью

* Созданный массив или структура доступны по ссылке с момента его создания до момента завершения программы.
* Другими словами, массивы и структуры продолжают существовать после завершения области видимости, в которой они были созданы.

## Выражение nil

- Выражение `nil` представляет значение, которое можно присвоить везде, где ожидается ссылка на какую-либо структуру.
- Доступ к полю значения `nil` приводит к ошибке времени выполнения
- `nil` допускается использовать только в контексте, где можно вывести конкретный тип структуры
- Допускается возвращать `nil` в любой из веток if...then...else

Примеры допустимых применений nil:

- `var a : record := nil`
- `a := nil`
- `if a <> nil then ...`
- `if a = nil then ...`
- `function f(p: record) = f(nil)`

Примеры недопустимых применений nil (в них нельзя вывести тип структуры):

- `var a := nil`
- `if nil = nil then ...`
