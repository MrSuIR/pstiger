# Грамматика объявлений языка Tiger

> ⓘ Данный документ описывает только правила, которые будут реализованы на текущем этапе.

Этот документ описывает правила синтаксического разбора объявлений языка Tiger

- Tiger — учебный язык программирования, разработанный Andrew Appel для книг и курсов в Princeton University.
- Описание основано на спецификации языка и примерах кода

## Краткое описание

В языке Tiger вся программа является выражением — в этом синтаксис Tiger похож на функциональные языки программирования, хотя и является императивным.

Объявления всегда находятся между ключевыми словами "let" и "in":

```
let
    var x := 15
in
    print(x)
end
```

## Грамматика в нотации EBNF

```ebnf
(* Список объявлений не имеет разделителей *)
declaration_list = declaration, { declaration } ;

(* Объявление символа *)
declaration = variable_declaration ;

(* Объявление переменной *)
variable_declaration = "var", identifier, [":", identifier], ":=", expression ;

```
