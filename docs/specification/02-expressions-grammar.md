# Грамматика выражений языка Tiger

> ⓘ Данный документ описывает только правила, которые будут реализованы на текущем этапе.

Этот документ описывает правила синтаксического разбора выражений языка Tiger

- Tiger — учебный язык программирования, разработанный Andrew Appel для книг и курсов в Princeton University.
- Описание основано на спецификации языка и примерах кода

## Краткое описание

В языке Tiger вся программа является выражением — в этом синтаксис Tiger похож на функциональные языки программирования, хотя и является императивным.

Поддержка классических выражений в Tiger устроена так:

1. Есть 12 бинарных и 1 унарный оператор
2. Выражения можно заключать в скобки
3. Последовательность выражений можно записать в скобках, разделив выражения запятыми
4. Есть литералы строк и чисел
5. Есть вызовы встроенных функций

## Операторы

Описание операторов

| Написание | Семантика                         | Особенности                  |
|-----------|-----------------------------------|------------------------------|
| \+        | Сложение чисел                    | Левая ассоциативность        |
| \-        | Вычитание чисел или унарный минус | Левая ассоциативность        |
| \*        | Умножение чисел                   | Левая ассоциативность        |
| \/        | Деление чисел                     | Левая ассоциативность        |
| \=        | Равно                             | Нет ассоциативности          |
| \<\>      | Не равно                          | Нет ассоциативности          |
| \>        | Больше                            | Нет ассоциативности          |
| \<        | Меньше                            | Нет ассоциативности          |
| \>\=      | Больше или равно                  | Нет ассоциативности          |
| \<\=      | Меньше или равно                  | Нет ассоциативности          |
| \&        | Логическое «И»                    | Вычисления по короткой схеме |
| \|        | Логическое «ИЛИ»                  | Вычисления по короткой схеме |

Приоритеты операторов (в порядке убывания приоритета):

1. Унарный минус: `-`
2. Умножение и деление: `*` и `/`
3. Плюс и минус: `+`, `-`
4. Операторы сравнения: `=`, `<>`, `<`, `>`, `<=`, `=>`
5. Логическое «И»: `&`
6. Логическое «ИЛИ»: `|`

Особенности операторов:

1. Операторы сравнения не ассоциативны
    - например, `a = b = c` не допускается грамматикой
    - при этом `a = (b = c)` допускается грамматикой
2. Логические операторы вычисляются по короткой схеме, то есть правый операнд не вычисляется, если левый уже даёт однозначный результат
    - например, здесь вызов функции f не происходит: `1 && f()`

## Последовательность выражений

Допускается писать в скобках последовательность выражений, разделённых точкой с запятой ";":

- В этом случае выражения выполняются последовательно и возвращается результат последнего: `(2 * 2; 2 * 5) → 10`
- Допускается пустая последовательность и она не возвращает значения: `()`

## Встроенные функции

1. `print(s: string)` — выводит строку в стандартный поток вывода
2. `printi(i: int)` — выводит целое число в стандартный поток вывода
3. `flush()` — записывает данные в буфере стандартного потока вывода
4. `getchar(): string` — читает один символ из stdin
    - возвращает пустую строку, если достигнут конец файла
5. `ord(s: string): int` — возвращает ASCII-код первого символа `s`
    - возвращает `-1`, если `s` пуста
6. `chr(i: int): string` — возвращает строку из одного символа для ASCII-значения `i`
    - программа аварийно завершается, если `i` вне диапазона \[0..127\]
7. `size(s: string): int` — возвращает количество символов в строке `s`
8. `substring(s: string, f: int, n: int): string` — возвращает подстроку `s`, начинающуюся с индекса `f`, длиной `n`
    - индексация символов начинается с нуля
9. `concat(s1: string, s2: string): string` — возвращает результат конкатенации строк `s1` и `s2`
10. `not(i: int): int` — если `i = 0`, то возвращает `1`, иначе возвращает `0`
11. `exit(i: int)` — завершает программу с кодом выхода `i`

## Грамматика в нотации EBNF

```ebnf
(* Программа — это одно выражение *)
program = expression ;

(* Выражения *)
expression = logical_or_expression ;

(* Логическое ИЛИ *)
logical_or_expression = logical_and_expression,
    { "|", logical_and_expression } ;

(* Логическое И *)
logical_and_expression = relational_expression,
    { "&", relational_expression } ;

(* Операторы сравнения *)
relational_expression = additive_expression,
    [ ("=" | "<>" | "<" | ">" | "<=" | ">=" ), additive_expression ] ;

(* Операторы сложения и вычитания *)
additive_expression = multiplicative_expression,
    { ( "+" | "-" ), multiplicative_expression } ;

(* Операторы умножения и деления *)
multiplicative_expression = unary_expression,
    { ( "*" | "/" ), unary_expression } ;

(* Унарный минус *)
unary_expression = { "-" }, primary_expression ;

(* Элементарное выражение *)
primary_expression = literal
    | identifier, argument_list
    | expression_sequence ;

(* Аргументы функций *)
arguments_list = "(", [ expression, { ",", expression } ], ")" ;

(* Последовательность выражений *)
expression_sequence = "(", [ expression_sequence_inner ], ")" ;
expression_sequence_inner = expression,  { ";", expression } ;
```
