# Типы данных

> ⓘ Данный документ описывает только правила, которые будут реализованы на текущем этапе.

Этот документ описывает семантику типов языка Tiger.

## Краткое описание

В языке Tiger есть два предопределённых типа данных:

1. `int` — целочисленный тип
2. `string` — строка

Кроме того, выражения могут не возвращать никакого значения — в этом случае их нельзя размещать в контексте, где ожидается значение.

## Литералы

Виды литералов:

1. Литерал числа, например: `2025`
2. Литерал строки, например: `"Hello, world!"`

## Операторы

- Для арифметических операторов `+`, `-`, `*`, `/` операнды должны быть целыми числами, результат — целое число
- Для логических операторов `&`, `|` операнды должны быть целыми числами, результат — целое число (1 или 0)
- Для операторов сравнения операнды должны быть оба целыми числами либо строками, а результат — целое число (0 или 1)

## Присваивание

Присваивание не возвращает значения, поэтому конструкции вида `a := b := 0` недопустимы.

## Конструкции, не возвращающие значений

Следующие конструкции никогда не возвращают значения:

1. Присваивания — например, `a := b`
2. Выражения области видимости `let ... in ... end`
3. Пустая последовательность выражений — `()`
4. Ветвления без ветки else — например, `if n > 0 then f(n - 1)`
5. Вызовы функций, для которых не объявлен возвращаемый тип — например, `function printLine(text: string) = print(text + "\n")`
6. Циклы while и for
7. Выражения break
