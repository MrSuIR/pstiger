# Типы данных

> ⓘ Данный документ описывает только правила, которые будут реализованы на текущем этапе.

Этот документ описывает семантику типов языка Tiger.

## Краткое описание

В языке Tiger есть два предопределённых типа данных:

1. `int` — целочисленный тип
2. `string` — строка

Кроме того, выражения могут не возвращать никакого значения — в этом случае их нельзя размещать в контексте, где ожидается значение.

## Литералы

Виды литералов:

1. Литерал числа, например: `2025`
2. Литерал строки, например: `"Hello, world!"`

## Операторы

- Для арифметических операторов `+`, `-`, `*`, `/` операнды должны быть целыми числами
- Для логических операторов `&`, `|` операнды должны быть целыми числами
- Для операторов сравнения операнды должны быть либо оба целыми числами, либо оба строками

## Передача параметров функций

1. Параметры передаются по значению — иными словами, присваивание параметра в функции не влияет на состояние переменных в других функциях.
2. Параметры можно использовать в левой части присваиваний, как и обычные переменные.
